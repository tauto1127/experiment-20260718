# SLAM Experiment Results (mros2-wasm-stable)

This report details the final results of the offline SLAM mapping experiment performed using the recorded rosbag play, ROS 2 Cartographer, and the `mros2-wasm-stable` node running inside `wamr-fast-interp-stable`.

---

## 1. Experiment Execution Summary

- **Rosbag Playback Duration**: **90 seconds** (100% played back)
- **WAMR Runtime**: `wamr-fast-interp-stable/product-mini/platforms/linux/build_cr/iwasm`
- **WASM Node**: `mros2-wasm-stable/cmake_build/occupancy_grid_node.wasm`
- **Communication Status**: **SUCCESS** (DDS participant and services matched over the network loop link)

---

## 2. Cartographer & WASM SLP Mapping Performance

During the playback, the WASM `occupancy_grid_node` dynamically subscribed to `/submap_list`, fetched submap textures using the `/submap_query` service, and successfully painted the map grid:

- **Submaps Painted**: **6 submaps** (Submaps 0 through 5)
- **Final Map Dimensions**: Width: **107 cells**, Height: **115 cells** (at **0.05m** resolution, yielding a **5.35m × 5.75m** physical grid)
- **Map Message Size**: **31,984 bytes** (successfully serialized and written to `/tmp/mROS2-data.txt`)

## 4. Conclusion
The experiment validates that:
1. **Lidar-based obstacle avoidance wandering** successfully explored and scanned the environment during simulation.
2. **`rosbag` playback** is fully sufficient to run Cartographer SLAM offline without running Gazebo.
3. **`mros2-wasm-stable` under WAMR** successfully handles high-frequency `/submap_list` subscriptions and `/submap_query` service client calls to paint a correct, dense occupancy grid map of the environment.
